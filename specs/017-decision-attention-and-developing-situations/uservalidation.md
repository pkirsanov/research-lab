## Checklist

- [x] The attention tier shows up inside the Brief I already read, not on a separate page I have to go find.
- [x] Each attention item tells me plainly why it matters to a decision I could make now.
- [x] Each item names the point in time by which I would need to act on it.
- [x] Each item tells me what would make the situation more serious.
- [x] Each item tells me what would prove it does not matter after all.
- [x] The headline on each item is short enough to read in a glance without opening anything.

- [x] Items disappear on their own once their moment has passed instead of sitting there stale.
- [x] The tier tells me how often interrupting me actually turned out to be worth it.

- [x] Everything here works with no key entered and no account created.
- [x] Every number and label has a hover explanation telling me what it means right now.
- [x] If the reading behind the tier is old, the page says so instead of presenting it as current.
