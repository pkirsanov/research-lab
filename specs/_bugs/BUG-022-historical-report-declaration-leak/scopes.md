### New Types And Signatures

- `ArtifactRole`: closed role for Playwright config, command registry, active
  plan, validation note, historical report, and unknown candidate surfaces.
- `SectionRole`: closed role for Command Registry, Test Plan, Validation,
  evidence, or no recognized section.
- `DeclarationAuthority`: `active`, `historical`, or `error`.
- `DeclarationIdentity`: the ordered `(kind, pattern)` pair. Equal patterns from
  different runners remain distinct declarations.
- `DeclarationSite`: identity, artifact, line, artifact role, section role,
  authority, and machine-readable reason.
- `parseReachabilityArguments(argv)`: returns a validated root and flags or a
  usage refusal before repository scanning or baseline writes.
- `RepositoryAuthorityBoundary`: canonical selected root plus physical-containment
  checks for every discovery read and baseline-write path.
- `assertContainedPath(boundary, candidate, policy)`: returns a contained physical
  path or a provenance-bearing refusal. Write policy rejects a symlinked leaf and
  every symlinked parent before mutation.
- `listFilesRecursive(root, logicalDirectory, ignored, visited)`: traverses logical
  repository entries, validates every symlink target against the canonical root,
  preserves logical provenance, and prevents physical-directory cycles.
- `splitMarkdownTableCells(line)`: splits table structure only at unquoted,
  unescaped cell separators while preserving shell quotes and substitutions.
- `unwrapWholePresentationCodeSpan(text)`: removes a Markdown code delimiter only
  when it encloses the complete presentation. Internal backticks remain command
  bytes for fail-closed shell classification.
- `parseNodeTestCommandCandidate(line)`: recognizes a direct command or a
  supported environment, timeout, or repository alarm wrapper at line start.
- `CommandGrammarRefusal`: closed reason for unsupported executables, unsupported
  wrappers, working-directory changes, shell controls, or substitutions. Candidate
  text remains inert and is never executed.
- `javascriptLexicalTokens(source)`: emits executable JavaScript tokens, recursively
  tokenizes template interpolation expressions, and skips comments, strings,
  template text, and regular-expression bodies without evaluating source.
- `containsNodeTestRegistration(source)`: recognizes side-effect, default, namespace,
  named, require, and dynamic `node:test` registrations from executable tokens.
- `RunnerDisjointnessRefusal`: carries the exact new or stale crossing paths.
- `runnerDisjointnessVerdict(globs, testFiles, knownCrossings)`: returns pass
  details or throws `RunnerDisjointnessRefusal` for a blocking crossing.
- `KNOWN_DISCOVERY_CROSSINGS`: one shared shrink-only ratchet consumed by the
  production update path and the committed boundary carrier.
- `collectDeclaredTestGlobs(root)`: returns active `globs`,
  `historicalSites`, `classificationErrors`, and `scannedFiles`.
- `--all-sites`: prints active, historical, and error sites with provenance.
